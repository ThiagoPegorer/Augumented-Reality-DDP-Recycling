## The four rules learned this session, all from Thiago catching a defect

1. **A value the source does not print is a derived value.** Print the source's numbers or name the
   derivation. Never write a computed value in the grammatical form of a reported one.
2. **Multi-measure studies:** list every outcome measure before writing, report those bearing on the claim
   and any that run against it. And read a control condition's description, not its one-word label.
3. **Never cite a review for a primary study's measurement.**
4. **Never lead a result sentence with the baseline.** The thing that changed takes the subject slot.

Plus two voice rules: **summarise the author's position, do not report their study** (omit n, protocol,
apparatus by default), and **do not carry the source's vocabulary into the paragraph**.

Plus one chapter-boundary rule: **a synthesis gathers findings that are on the page; a discussion interprets
findings against the author's own results.** The tell is citation density.
